# Morse Player

Morse Player converts typed text into audible Morse code through the Flipper
speaker. It does not transmit over Sub-GHz, NFC, BLE, or any other radio.

## Use

1. Open **Tools → Morse Player** and select **Enter text**.
2. Press **OK** to finish input and review the text plus its Morse form.
3. Press **OK** again to play the sequence.
4. Press **OK** while playing to stop, or press **Left** to edit the text.

The preview reports unsupported symbols instead of producing accidental tones.
The codec accepts ASCII letters, digits, common punctuation, and Russian
Cyrillic letters. Speed, tone frequency, and volume are configurable in
**Settings**.

# Upstream provenance

TumoKey vendors and adapts the source of:

- Project: ZeroFIDO
- Repository: https://github.com/MinorGlitch/zerofido
- Upstream commit: `56b433f9d1390ad224246c85a06083b40de4903e`
- Upstream release baseline: `v0.7.0`
- Original author: Alex Stoyanov
- License: GPL-3.0-or-later
- Imported: 2026-07-23

The original copyright and GPL notices are retained in the imported source.
Tumoflip changes the application identity, storage namespace, distribution
path, product documentation, and release/acceptance gates. Internal `zf_` and
`zerofido_` symbol prefixes are intentionally retained to make future source
audits and upstream synchronization reviewable.

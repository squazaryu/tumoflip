# Tumoflip Dev 008-028

- Fix TextInput's temporary draw buffer so the cursor and ellipsis cannot write
  past its end. This was reproduced with AddressSanitizer while rendering the
  Weather Editor Sensor ID input.
- Accept Kia V5 files with exactly 64 or 67 bits in both the core and
  ProtoPirate file parsers, preserving the recorded payload and length.
- Prepare Weather Editor as an independent FW Package. Its UI uses wider
  value columns, separated station metadata, readable sensor values and an
  About view with proper padding. Profile loads are transactional; saves do
  not overwrite existing files and report write/close failures.

Firmware API remains 88.7. Weather Editor is excluded from updater resources;
install it using the corresponding FW Packages Dev revision.

Validation includes native C/U8g2 screen renders, AddressSanitizer input and
navigation checks, storage fault-injection tests, firmware/FAP builds and
updater/package verification. These are software checks, not hardware acceptance.

After installing, check normal boot and opening/closing apps, separate Standard
and Read RAW settings, and opening existing Kia V5 captures. After installing
the package, check Weather Editor's Receiver, Load saved, configuration, numeric
and hexadecimal entry, save/reopen, and return navigation. Validate weather
sensor RX/TX only with your own sensors; check external-radio disconnect and
reconnect separately. No user capture cleanup or firmware settings reset is
required by this release.

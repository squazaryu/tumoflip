# Tumoflip Dev 009-016

## Changes

- NFC, iButton and SD input handling: bound SmartPoster nesting and DESFire
  access-right bytes, reject unknown saved iButton protocols before group
  lookup, and fail TAR extraction on a negative read or partial write.
- RPC app launching: caller-supplied arguments cannot impersonate an internal
  RPC context. Callback registration accepts only a live service context.

F7 API remains **88.14**. Existing LF RFID numeric protocol IDs stay unchanged;
the upstream Indala224 reorder requires a separate API migration and FW
Packages rebuild. This release does not contain the Specter 3.3 FAP candidate.
No saved files, user settings or paired packages are removed or migrated.

## Validation and installation

The exact Dev 009-016 source passed 1040 host tests, F7 updater/FAP build and
APPCHK, Sub-GHz feature-import validation and native Weather Editor rendering.
The release validator accepted the updater and SD manifest: physical C2 gap
12,288 bytes, updater 120,073 / 131,072 bytes, API 88.14. Back up `/int` and
important SD files before installing this Dev build.

Hardware acceptance remains open: known-good and malformed NFC/iButton files,
SD archive extraction, BLE/USB App Bridge app start/exit/reconnect, and ordinary
Sub-GHz/FAP smoke tests. CI does not mark these physical steps passed.

This is a Dev prerelease for functional testing, not a stable promotion.

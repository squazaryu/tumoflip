# Tumoflip Dev 009-020

## Changes

- Ignore macOS Finder metadata (`.DS_Store` and `._*`) while generating icons,
  FAP assets, resource distributions, manifests, and resource tarballs.
- Track real FAP asset-tree changes and current embedded-plugin FAL targets so
  stale staged plugins cannot break an all-app distribution build.
- Fix Speaker Debug's private `note_frequency_from_semitone` dependency without
  exporting a new firmware API symbol.

No Sub-GHz protocol, radio behavior, user file format, or saved-data migration
changes are included.

## Compatibility

- F7 API remains **88.15**.
- Stable firmware and the FW Packages catalog are not changed by this release.
- No TumoCompanion/iOS update is required for these build-tooling changes.

## Verification

- Focused asset, embedded-FAL, Speaker Debug, release-workflow and SCons
  distribution-order tests passed.
- Speaker Debug passed strict FAP import validation; the full local FAP
  distribution and the merged PR firmware CI build passed.

This is a Dev prerelease, not a stable promotion. No new hardware behavior was
introduced or claimed as device-tested.

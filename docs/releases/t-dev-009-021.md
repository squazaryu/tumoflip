# Tumoflip Dev 009-021

## Changes

- NFC: add Texkom TK13/TK15/TK17/MMBIT detection, reading, saving, and emulation.
  Add Manually creates TK13, TK17, and MMBIT samples with random UIDs and valid
  checksums. TK15 is read/emulated but is not a separate generator because its
  frame is TK13 with timing variation.
- NFC: report the FeliCa Standard system key version from the system node rather
  than copying Area 0000's key version. Save format v4 records the values
  separately; legacy v3 files remain loadable and show the system key version as
  Unknown because v3 stored the root-area value there.
- NFC: make the CLI protocol-name lookup safe for newly supported protocols and
  use generic NFC technology/UID accessors in Add Manually, avoiding an
  NFC-A-only assumption for Texkom.
- Firmware API is **88.17**.

## Compatibility and package status

- FeliCa version-3 files remain readable; no card data is rewritten by loading
  or reading. System key version becomes Known only after a successful system
  node request.
- The release updater also includes a fresh `tumoflip-packages.json` and
  `tumoflip-packages.zip` bundle generated from this firmware commit and API.
- No TumoCompanion/iOS code change is required. The separate FW Packages Dev
  catalog is independent and remains API-major compatible; no package FAP source
  changed in this feature.

# Tumoflip Dev 009-022

## Changes

- Sub-GHz Add Manually now supports Nice O-Code at 433.92 MHz. The regular
  generator creates a new controller file; Advanced mode lets you enter the
  known installer code alongside the serial, button, and counter.
- Generated files store the 16-bit `IC` field required to identify and decode
  O-Code. The reserved `FFFF` plain FloR-S marker, serials above 28 bits, and
  buttons above 4 bits are rejected. Generation fails if the Nice rainbow table
  is unavailable.
- Existing Nice FloR-S and Nice One generator APIs and routes remain unchanged.
  The separate Nice O-Code recovery app's New-remote action is not included.
- Firmware API advances from **88.17** to **88.18** with one additive
  `subghz_protocol_nice_o_create_data` symbol. The local Sub-GHz feature-plugin
  ABI marker advances to **1003**.

## Compatibility and package status

- The updater includes a package manifest and ZIP generated for this firmware
  build. No custom FW Packages FAP payload changed, so no separate FW Packages
  catalog revision is required.
- The external Community Pack 11oct2026 remains a separate audited source; this
  release does not copy its binaries or change the pending audit disposition.
- No TumoCompanion/iOS change is required.

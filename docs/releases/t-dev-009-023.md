# Tumoflip Dev 009-023

## Changes

- TumoSpectrum 3.3 adds `Capture Sets` with a native archive browser and the
  existing latest-set shortcut. Saved analyses can be reopened independently
  from their original source captures.
- New capture sets record each `.sub`/`.ir` source path, byte length, and
  SHA-256 digest. Source checks distinguish unchanged, changed, missing, and
  unreadable files. Legacy schema-1/2 sets remain readable and are explicitly
  unverified; a saved analysis is not silently replaced when its source changes.
- Text reports use create-new names. Source captures remain read-only, and
  archive browsing/checking adds no radio transmit operation.
- TumoSpectrum FAP version advances to **3.3.0**. Firmware API remains **88.18**.

## Compatibility and package status

- TumoSpectrum is part of the firmware resources in the updater; no separate
  FW Packages FAP payload changed, so no new FW Packages catalog release is
  required. The firmware release still includes a manifest and ZIP generated
  for this exact firmware commit.
- No TumoCompanion/iOS change is required.
- Capture-set schemas 1 and 2 remain loadable. Schema 3 adds source fingerprints;
  it does not authenticate files or make a changed source equivalent to the
  saved snapshot.

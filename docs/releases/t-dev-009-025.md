# Tumoflip Dev 009-025

Selective Unleashed 094 adaptation, not a Stable promotion.

## Changes

- Missing radio presets fail safely across Standard Sub-GHz, ARF, SubGHz Remote,
  Companion, Quac, Wardriving and Weather. ARF manual Security+ generation no
  longer leaks or overwrites an active transmitter.
- Nice FloR-S/One, Came Atomo and Beninca ARC receive grouping retains distinct
  buttons/transmitters/frequencies. Came inspection preserves the original key.
- Nice O-Code 112-bit captures retain their raw tail. Unknown installer-code
  captures are saveable but explicitly RX-only, without reserving IC `FFFF`.
- Nice O-Code and explicit Security+ PIN sends support external CC1101 through
  our radio broker, with busy/failure/disconnect cleanup. No new recovery or
  automatic PIN-search capability is introduced.
- HomeGate 433.92 MHz / AM650 manual profile and supplemental system keystore.
  User keystores, saved captures and existing menu IDs are preserved.
- Storage RPC supports bounded offset/size reads with explicit acknowledgements
  and unchanged legacy whole-file reads. This alone does not fix background BLE.
- Private button tables and compact label IDs recover about 2 KiB of flash,
  restoring the full **4096-byte physical reserve** without removing functions.

## Compatibility and packages

- F7 API **88.20** adds three query helpers; public layouts and existing exports
  are unchanged. The private Sub-GHz feature ABI stays **1003**.
- Nice O-Code / Security+ PIN **1.1**, Quac **0.12.0**, Weather Editor **2.5**.
- This firmware release carries its own matching package manifest/ZIP. Quac and
  Weather remain package-only; flashing the updater does not replace those FAPs.
  Their independent FW Packages revision is published/recorded separately.
- TumoCompanion ranged-read source support is merged in PR #228. No iOS release
  is included here; older clients keep working with whole-file reads.
- Older firmware does not understand the new RX-only Nice marker. Use pulse RAW
  when moving unknown-code captures to older firmware for analysis.
- Stable remains unchanged. Back up `/int` and important SD files before flashing.

Hardware acceptance is pending, not replaced by these tests.

## Device checks after installation

1. Confirm version/API, boot, SD access, BLE/App Bridge and ordinary FAP launch/exit.
2. Open/play existing valid Saved Sub-GHz files on owned receivers; try an unknown
   preset in a disposable copy: a clear failure, never a crash or stale modulation.
3. Check ordinary RAW/Auto Decode, packet grouping, different buttons and hopping.
   Inspect and reopen saved Came captures; original key data must not change.
4. Test Nice reception and manual Security+ sends on owned equipment, internal
   and external CC1101. Busy radio and unplug/replug must recover without hanging.
5. Check HomeGate generation/save/reopen and owned receiver behavior. Confirm
   supplemental system keys load without changing the user keystore.
6. After installing the matching package updates, smoke-test Quac and Weather
   start/stop/back. Existing weather recordings/settings must remain available.

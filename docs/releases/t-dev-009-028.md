# Tumoflip Dev 009-028

## Changes since 009-027

- **Standard Sub-GHz / Saved RAW / More / Nice O-Code:** analyze the selected
  RAW file in Nice O-Code 1.3 without a second file picker. Standard restores
  its original protocol pack and exits before the FAP starts. Exiting Nice
  returns to Standard's start screen; Auto Decode keeps its existing workflow.
- **Bounded, read-only RAW analysis:** Standard and Nice share the sample reader.
  Offline Nice does not acquire a radio or rewrite the source recording. EOF,
  not the progress animation, controls completion; Back stops and joins the
  worker before teardown. Save remains explicit and creates a separate file.
- **Nice O-Code 72-bit framing:** corrected parcel k bytes and the end-of-press
  flag on the final two parcels. Ordinary Nice One and 52-bit FloR-S retain
  their behavior. Synthetic native tests inspect all 16 encoded parcels.
- **Passive 112-bit certificate display:** show `Cert(CRC)` after structural
  checks, including without a recovered installer code. Conflicting values are
  hidden. Explicit save may add `Analysis_Cert` to a new analysis file; CRC does
  not establish ownership or permission to enroll a transmitter.
- **Native Nice UI checks:** 14 states rendered with production draw code and
  firmware fonts, including RAW progress, long counters, errors and conflicts.
  This is not a claim of physical-device display acceptance.

No 112-bit transmission, automatic certificate enrollment, automotive PIN/seed
search or new radio frequencies are added. Existing installer-code analysis is
reused without expanding its search. See the [implementation notes](../nice-raw-passive-analysis.md).

## Compatibility and installation

- Public API **88.21** and private Sub-GHz feature ABI **1003** are unchanged.
- Install through **TumoCompanion / Firmware / Dev / 009-028**. Use the normal
  updater, which includes the matching Nice FAP resources. The release also
  provides its matching firmware-baseline package manifest and ZIP.
- Independent **FW Packages Dev 025 remains compatible**. Its bounded Quac and
  Weather Editor delta does not overwrite Nice O-Code or the Standard firmware.
  No separate FW Packages catalog or iOS release is needed for this change.
- **Module One / RX Link is unchanged.** This updater does not flash ESP32 or
  replace Marauder. The optional experimental classic-ESP32 backend remains on
  [009-026](https://github.com/squazaryu/tumoflip/releases/tag/t-dev-009-026),
  with its original source identity and hashes; it is not for ESP32-C5.
- Back up important SD files and `/int` before installing. Stable is unchanged.

## Verification

Implementation PR [#558](https://github.com/squazaryu/tumoflip/pull/558) passed
1150 host tests, native ASan/UBSan framing/CRC/RAW/UI regressions, validation of
298 built FAP/FAL metadata records, and F7/CodeQL CI. The tested implementation
has a **4096-byte physical C2 reserve**, a 4208-byte section gap, and 72 bytes
more core code/constants than 009-027; this is not a flash-saving change.

Publication additionally requires rebuilding the exact version-merge SHA,
repeating the full host/native/artifact checks and strict 4096-byte gate, then
downloading every uploaded asset and verifying it against the local SHA ledger.
Hardware RF/SD acceptance remains pending; no Stable promotion is implied.

## Hardware checks after installation

1. Confirm **009-028 / API 88.21**. Smoke-test Saved/RAW, NFC, BLE Remote and FAPs.
2. On copies of your own RAW recordings, open **More / Nice O-Code**; cancel
   during reading and analysis, reopen, and confirm return to Standard and the
   original protocol pack. Confirm source files are unchanged.
3. Check valid, empty, truncated and corrupted RAW files. A percentage must not
   finish processing early, and errors must not leave an old loading screen.
4. Check existing 52/72-bit Nice files and your own remote/receiver. A passive
   certificate must not be presented as successful installer-code recovery.
   Save/reopen a separate analysis file without overwriting existing captures.

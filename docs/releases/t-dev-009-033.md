# Tumoflip Dev 009-033 — Field Apps

Dev candidate for user testing, not a Stable promotion or hardware certification.
Public F7 API remains **88.23**; retain the full **4096-byte physical C2 reserve**.

## Included

- **Servo Tester+ 1.0**: explicitly armed 50Hz hardware PWM on PA7/pin2,
  bounded pulse calibration, stop/cancellation and app-owned optional GPIO5V.
  External servo power is the default; the UI reports microseconds, not an
  unmeasured shaft angle. The upstream MIT notice is embedded in the FAP assets.
- **Power Journal 1.0**: passive app-only power telemetry, bounded history,
  qualified discharge-capacity observations and checked new CSV exports.
  No charge-control changes or background/idle sampling guarantee.
- **Sensor Watch 1.0**:25 existing Weather Editor RX decoders, up to8 identified
  sensor cards with32 observations each, age/temperature history and checked CSV.
  Internal CC1101, explicit AM650 reception; no automatic RX or TX.
- **Varta Inspector 1.0**: cancellable own EM4100 observations and strict saved
  RFID/T5577 inspection. Read-only files, parity/read-mask validation, no password
  imports, protected-read commands, marker emulation, key reconstruction or tag writes.
  Matching a prefix/marker never claims authenticity or access authorization.
- **Tumo UHF Inventory 1.0**: explicit bounded UCM601 UART inventory,32 EPCs,
  strict checksum/address/PC-length validation and checked CSV. A separate powered
  UHF reader is required; Module One/ESP32-C5 alone is not that reader.
- **Device Library 1.3 / TumoSpectrum 3.6**: deferred Sensor Watch launches with
  per-object history and resource release. TumoSpectrum also contains the existing
  receive-only Envelope Check previously delivered by FW Packages Dev029.
- **CAME Atomo inspection**: unsigned byte assembly fixes signed-shift undefined
  behavior found by fatal UBSan; original captured data is retained. Encoder and
  create-data paths are unchanged by this correction.

The emulator remains deferred and is not shipped. Ordinary Community Varta,
UHF Expansion and gbhobbytech Servo retain separate IDs; existing capabilities
are not removed. There is no iOS patch, ESP32 backend update or device flash here.

## Install

Back up `/int`, important SD files, recordings and object/history data first.

1. Existing **TumoCompanion1.11.32** is sufficient.
2. Install **Firmware → Dev →009-033**, including its native resources.
3. Refresh **FW Packages → Dev030** and install **Base** plus **Module One**.
   These are cumulative packages; the five new FAPs are not installed by firmware
   flashing alone. Check that the independent030 release is available first.

Menu routes after package installation:

- Apps → GPIO → Servo Tester+.
- Apps → Tools → Diagnostics → Power Journal.
- Apps → Sub-GHz → Sensor Watch; also Device Library → object → Sensor Watch,
  or Apps → Module One → Signals → TumoSpectrum → Sensor Watch.
- Apps → RFID → Varta Inspector.
- Apps → GPIO → Tumo UHF Inventory.

Sensor Watch does not need Module One hardware despite TumoSpectrum's existing
folder. New histories/reports live under `apps_data/device_library`; they are
user data, not package overlays. Source recordings are not deleted or rewritten.
No schema/API-breaking migration is introduced; older object cards still load.

## Checks and acceptance boundary

Implementation [PR571](https://github.com/squazaryu/tumoflip/pull/571) passed1269
local host tests and F7/Linux CI. Native C models, UART/coil/PWM ownership and
SD-failure fixtures use fatal ASan/UBSan.45 native GUI states cover errors,
scrolling and long values using real draw callbacks/stock fonts. All measured
new model/store/controller files exceed80% line/region coverage; this is not
coverage of the entire firmware or physical RF/electrical behavior.

Publication requires a fresh exact merged-version build, ELF/DfuSe/SDK/archive
checks and downloaded-asset byte verification. Firmware and the independent
FW Packages catalog have separate immutable identities.

**Test on hardware after installing the Dev:** measure PWM without an actuator
first, then use a safe unloaded fixture; compare power telemetry with stock
diagnostics; receive owned sensors and test object/global history isolation;
cancel LF reads and re-open stock RFID; verify UHF stop/timeout/unplug behavior
on the correct reader. No device was flashed by the release process.

See [full scope and acceptance matrix](../product/field-batch-2026-10.md).
Independent agent/human review and hardware acceptance are not claimed.

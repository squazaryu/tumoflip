## Integrated selections

1. **FatFs/exFAT correctness**, official `d8dfb3147c31c25fe2b69c4a4eed1c04451fa30e`.
   Fix uninitialized fragmentation state, reopened/truncated contiguous files,
   and directory growth. The actual target FatFs runs against a RAM-only block
   device in regression tests. This does not establish the cause of historical
   missing user recordings.
2. **Shared LF RFID write filling**, `a70a69d9d47c1e0a3b1f868aa25c4d0a7a5346d5`.
   Private helpers replace duplicated byte-buffer/T5577/EM4305 request filling.
   Keri's local data normalization and Gallagher's bit-offset special case are
   preserved. No protocol IDs, target IDs or public write-request layouts change.
3. **FDX-B reception and ASK 134.2 kHz**, `525dcce0e461d4f4b852a32cc6e3b4d075b50f17`.
   Add manual/CLI/RAW 134.2 kHz and the third auto-read step. Keep CRC checks and
   add duration bounds, one-shot pulse consumption and overflow protection to
   the upstream duty-skew decoder. Existing public enum values remain stable.
4. **RFID/iButton status layout**, selected from `b510f625dd` and `2cdc85a6ae`.
   A new opt-in `popup_set_text_width` fits each explicit text line by pixel width,
   preserving legacy behavior at width zero. Long names cannot overlap icons.
   Non-ASCII filenames use a display-only “Saved Tag” fallback with the current
   bitmap font; actual names and paths are never changed.
5. **Sub-GHz Remote held/released transmission**, adapted from upstream boundary
   `a94f7c754f4e0f9881b7f3432906b46da4007e21` →
   `df6334cdde0c88e22ab09ba16b12222cfccf834a` (Unleashed `79f306afbb`).
   Keep Tumoflip radio broker and fail-closed preset checks. Release finishes the
   current frame/repeats, held RAW restarts only after EOF, Back stops immediately.
   Stop the old map entry before selecting the next. Decoder/encoder ownership
   is explicit; no delayed RAW completion event can reach a freed app. Deserialize
   once when starting so a press does not increment the rolling counter twice.
   Restore a custom button with the radio **off**, never by extra RF transmissions.
   The established D-pad UI is retained rather than importing the full new UI.
6. **Quac held transmission**, Community `6a81d05018` (local 0.12.1).
   Adapt the same frame-completion semantics with a 5 ms cancellable wait, not
   upstream's uncancellable delay loop. RAW completes once; Back still cancels.
   Reset protocol/custom-button state on cleanup and preserve user Repeat fields.
7. **Checked signal saves** shared by Remote and Quac in the FAP-linked
   `signal_file` library. The previous delete-before-write implementation is not
   retained. Create `.tumo-bak` with CREATE_NEW, flush/close/read-back verify it,
   overwrite the existing original with checked byte counts, truncate/flush/close,
   and read back the new contents. On failure attempt rollback and retain the
   verified backup. Never overwrite a pre-existing backup or remove the original.
   This is recoverable error handling, **not atomic power-loss protection**;
   callers must serialize writes. FatFs storage rename is copy/delete and is not
   used as an atomic replacement. Errors are reported to the user.
8. **Official visible-string corrections** `66613d2b46`: two Infrared messages and
   updater “Stack”. NFC credit strings were already corrected by our safer parsers.

Public F7 API is **88.22**, adding only `popup_set_text_width` as a core export.
The signal-file helper's declaration and static library are in the SDK, but the
function is deliberately **not** exported from resident firmware. Private
Sub-GHz feature ABI remains **1003**. Upstream's identical API number does not
mean an identical set of exports.

## Not imported wholesale

- `5082af55ba`: the smaller decimal parser changes `strtod/strtof` semantics
  (including hex/Inf/NaN and rounding). No public numeric functionality is
  removed to chase flash space.
- Full T5577 `1672f7c54d` plus its Saved-list/favorites follow-ups is a broad
  worker/UI/ABI rewrite. Do not conflate it with the narrow shared write filling.
  A separately budgeted/lazy-loaded architecture is preferable to weakening the
  4096-byte reserve or faking MultiWriter's API.
- `44ef0b91ea` rolling Nero support is not imported as a replay encoder. A passive
  decoder-only candidate needs separate fixtures and plugin/radio-budget review.
- Nice certificate/112-bit TX/enrollment patches (`3c6d6fa34f`, `3c5f8a29cc`,
  `2534886419`) are outside the selected passive 112-bit path; do not erase our
  explicit “installer code known” semantics. Existing 52/72-bit functionality stays.
- ProtoPirate 4.1 is a large plugin-host/settings rewrite (131 files relative to
  the previous source boundary). Direct CC1101 Remote Analyzer access must be
  adapted to our broker, and Standard already owns important receive/decode flows.
  Its keyboard-lock fix concerns views owned by that new plugin architecture;
  it is not a drop-in patch for our current views. No new automotive brute force,
  wholesale protocol removal or duplicate Standard UI is included.
- Marauder v1.19.2 allocates the CSI sample queue only while active and frees it
  on stop/failure. This benefits **ESP32 RAM**, not Flipper core flash. The release
  has a C5 DevKitC-1 asset; retain the separate Module One v6.1 hardware contract.
  Neither device was flashed and no installer/catalog baseline was auto-accepted.

## Verification and delivery boundary

- Actual target FatFs: 9 RAM-only FAT/FAT32/exFAT create/append/truncate scenarios;
  the old exFAT failure was reproduced before the fix.
- Shared RFID requests: 20,480 old/new comparisons with canaries, including Keri,
  Securakey branches and unsupported target types.
- Actual FDX-B: clean/weak/skewed 125/134.2 kHz synthetic signals, bad CRC, malformed
  durations and constructed signed-overflow pairs under hard-failing ASan/UBSan.
- Native Remote scene/radio: release completion, held RAW EOF, selection order,
  start failures, exit ownership, encoder-only button restoration and no extra TX.
- Signal saves: in-memory partial writes, opens/reads/sizes/truncate/sync/close,
  collisions and second failures during rollback; original or verified backup
  retained. Production helper coverage: 100% lines, 91.33% regions.
- Quac production ownership/parser coverage: IR 100/100%, Sub-GHz 94.63/91.67%,
  start 100/83.61% lines/regions.
- 12 native-font RFID/iButton frames checked for bounds and visually inspected.
  These previews are not physical LCD acceptance.
- Full local unittest discovery: **1164 tests passed**, no skips. The native ELF
  metadata reader additionally accepted all **298 top-level FAP/FAL artifacts**.
  `fw_dist`, `fap_dist`, `updater_package`, API/APPCHK and the strict 4096-byte
  erase-aligned DFU validator passed. Three Sub-GHz feature-host import contracts
  resolved (64/63/55 imports, respectively). New tests are registered in PR/release CI.
- Independent agent review and physical-device testing have not been performed;
  native fixtures, self-review and CI must not be presented as either of those.

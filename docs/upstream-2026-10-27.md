## Integrated: TumoSpectrum 3.5.0 / Envelope Check

The same `signal_workbench` id and `Module One/Signals/signal_workbench.fap` path
remain protected/managed. Open **Apps → Module One → Signals → TumoSpectrum →
Envelope Check** after the updated package is delivered. The new code is entirely
inside that FAP; firmware API remains **88.23**, with no iOS/protobuf change.

- INT or external CC1101, owned through the existing radio broker. Band Map's
  selected frequency is the starting point. No TX, file write, delete or guessed
  modulation/preset application occurs.
- Release the transmitter on entry and before **OK / CAL** to learn the quiet
  floor. Left/Right tunes 25 kHz; Up selects INT/EXT; Down selects the next common
  band; Back releases/frees the sampler. Missing/busy/error states permit retry.
- 128 bounded samples target 100 µs spacing using existing RSSI calls. SPI is
  released between samples and the sampler yields to other work. A 50 ms window
  budget rejects prolonged sampling, after an individual driver call returns;
  the driver call itself cannot be preempted by this budget. The millisecond-tick
  period field is an upper estimate, not a calibrated sample clock.
- The private sample/floor type is 16-bit: both CC1101 drivers legitimately
  return down to **-138 dBm**, below signed-byte range. All 256 raw RSSI byte
  values and weak pulses below -127 dBm are covered; a quiet channel is not
  reported as a Read error. The controller remains below 512 bytes in the native
  allocation-size assertion; no public API or persisted file format changes.
- Pulsed / Flat carrier / Unclear are amplitude-envelope evidence only. A flat
  carrier can be FM, CW, interference or other signals; rapid bursts can be
  missed. Percent is agreement of the last at most 24 windows, not probability
  of a modulation/protocol match. Six windows and 80% agreement are required.
- Quiet/no-signal, overload and bad input clear previous verdicts. Calibration,
  tuning and changing radios also clear results. No idle background service or
  growing history exists. GUI receives a locked snapshot, not a sampler pointer.

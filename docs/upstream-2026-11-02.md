## Integrated adaptations

- [Official #4483](https://github.com/flipperdevices/flipperzero-firmware/commit/9981d9d4aa5ec7b14bb46cf15763dd293a7dec6a): reject non-I2C Ultralight READ/WRITE when the start page equals the page count. Preserve the I2C validator.
- [Unleashed `f5e39f9`](https://github.com/DarkFlippers/unleashed-firmware/commit/f5e39f9115f18ded8a41c5316b15c83124307346): validate the total Ansonic bit period so slow Nice-like pulses do not become false Ansonic frames. Sum durations in 64 bits. Reject CAME TWEE parcel `0xF` before table lookup, UI decoding or upload; do not clamp malformed data to parcel 14 as upstream does.
- [Unleashed `6197941`](https://github.com/DarkFlippers/unleashed-firmware/commit/6197941a067ff67864b521bcf33bae2d27bb64be): correct Dooya's reported upload length (83, not 82 timings); allocate CAME Atomo 1024, Power Smart 1040 and Somfy Keytis 560 timings; require exact frame lengths for Atomo/Keytis/Telis. Preserve our Dooya command selection and captured-OK behavior, including no automatic Key rewrite.
- [Unleashed `1804b39`](https://github.com/DarkFlippers/unleashed-firmware/commit/1804b3982b39d3d839b8dccce5959a46be736be5): adapt lazy BinRAW capture buffers only. Use the existing private, non-fatal optional allocator rather than upstream's racy free-block preflight followed by mandatory malloc. A single 10240-byte block owns both payload arrays; it is retained until decoder destruction. Failed allocation leaves both pointers null and permits a later retry. Disabled RAW does not receive RSSI arming ticks in Standard (including diversity), ARF or Wardriving. Hash, display and serialization handle the never-allocated state; loading a saved BinRAW allocates on demand.
- [Community Wardriving `46b1fca`](https://github.com/xMasterX/all-the-plugins/commit/46b1fcad7cdeb9031b98912bfaeb080c6c61c270): adapt its distinction between total heap and largest contiguous block. Decoded-history admission requires 6144 bytes free and a 1032-byte block; BinRAW requires 14336 and 6152. Keep the existing 15-item limit, lazy RX/GPS plugin, radio broker and GPS calculations. Local app metadata advances from the default 0.0 to 0.1.

The 10 KiB saving is **RAM per decoder whose BinRAW has not been used**, not
flash. Two such diversity decoders avoid 20 KiB of eager payload allocations.
Once RAW is used, payload memory remains allocated until that decoder is freed.
Under fragmentation, requiring a single 10 KiB block may refuse RAW where two
smaller blocks could fit; this path fails non-fatally rather than assuming OOM
cannot happen. Wardriving's admission thresholds reduce risk, not a universal
guarantee against concurrent allocations. Its generic status indicator uses the
decoded threshold; a larger RAW record can be refused sooner.

To preserve the existing 4096-byte flash reserve, six existing Manchester
encoders share one private timing-conversion implementation. All four enum
values retain their exact short/long, low/high mapping and the invalid-value
crash behavior. GCC LTO is prevented from cloning this small shared primitive
back into six copies. It adds no SDK/plugin export or protocol feature.

## Reviewed, not copied

- Unleashed's new KeeLoq mode-7 forced-resync changes and T5577 password-sniff/dictionary workflow are not part of the agreed own-device analysis scope. Existing functionality is not removed. No KeeLoq source is changed by this batch.
- The rest of the RX-history rewrite (held global TX allocation, history growth, full-state hysteresis and automatic item eviction) needs a separate broker/diversity design review. No new SD deletion, RAM eviction loop or Saved-file filtering is introduced here.
- [ARF `dev-7e3d1081`](https://github.com/D4C1-Labs/Flipper-ARF/releases/tag/dev-7e3d1081) is **not unchanged**: its two new main commits contain large app-tree moves/restorations, RAW Edit changes, Fiat/Renault recovered-key database lookup/save and new frequency/RSSI helpers. This is not a new standalone decoder/frequency patch to transplant. In particular, its registry removes Princeton, which stays enabled here. Its SPI-held sampling helpers duplicate our bounded envelope-analysis path and lack equivalent time/count bounds. No new ARF key recovery, database or brute-force flow is imported.
- Community PicoPass 1.23 changes NR-MAC persistence to append, adjusts C1k35s facility-code bounds and changes dictionary-related flows. PicoPass stays Community-managed. No bulk app replacement or user dictionary deletion is performed.
- No new Momentum source delta or Marauder source delta was found at these refs.

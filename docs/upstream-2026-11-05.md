## Selected adaptation

From [Unleashed2d89f1e](https://github.com/DarkFlippers/unleashed-firmware/commit/2d89f1e1f420fc011b2019fd100fd3deed216e5f):

- **Hormann HSM:** accept the legitimate seven-one as well as eight-one
  preamble. Require all seven shared bits and both stop bits, and exactly44
  bits. Reject overlong input before the8-bit counter can wrap. Existing
  encoder/framing and UI names remain unchanged.
- **KeeLoq TE200us:** lock measured TE156..244us from the fast sync gap;
  retain the existing nominal400us timing/tolerance path. The sync bands
  overlap, so unlike a literal upstream port the fast choice also requires
  a fast preamble. A nominal400us preamble with sync2201..2449us continues
  to decode as400us rather than being stolen by the fast branch.
- Scale only existing pulse timings, not key/counter-generation semantics.
  Save a nominal `TE: 200` only for a fast capture. Loading an absent,
  unsupported or out-of-range TE falls back to400us on every load; missing
  TE must not inherit the previously opened file's speed. A TE write failure
  is an error. Standard captures keep their existing serialized layout.
- Bound KeeLoq frames to64..66 bits before a malformed stream can wrap the
  bit count. Preserve received Erreka seeds, Monarch metadata, KEY/new-Monarch
  receive-only restrictions, current counter modes and all custom buttons.
- Store measured TE in existing decoder padding; do not change public
  decoder/generic structs, exports, plugin API or the radio broker.
- Keep one private metadata reader for both load paths rather than duplicating
  Seed/Manufacture/TE/CounterMode parsing. A failed rewind is an error for
  both callers, and a parser's output is ignored when its read returns false.
  Build the original400us upload, then halve only the newly appended frame
  for a TE200 file. Existing upload prefixes are never scaled twice.

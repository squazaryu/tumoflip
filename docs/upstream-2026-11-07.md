## Implemented, not wholesale cherry-picks

### Archive safety

Adapt the remaining gaps from [official4509](https://github.com/flipperdevices/flipperzero-firmware/commit/389fb35f9929771b6db87d8fc89ec126f30e515d).
Removing an unloaded/empty selection cannot underflow the list. Reordering
requires a complete favorites list, a valid selection and a nonzero direction;
indices above255 remain intact. A failed explicit file deletion retains its
favorite and browser row. No automatic deletion or migration is introduced.

Bounds/null checks, icon ownership/self-assignment and settings-argument handling
were already covered locally. Keep the checked transactional favorites writer;
do not replace it with upstream's unchecked remove/rename sequence.

### Partial CLI offload, with recovery commands retained

Selectively adapt [Unleashedb1829693](https://github.com/DarkFlippers/unleashed-firmware/commit/b18296933c0dda06935afaf0b6a556e1cbb45362).
Move only gpio/led/vibro/i2c to native lazy-loaded CLI FALs, retaining their
handler bodies and command flags. The release validator requires the exact
four module bytes in both resources and resources.ths. These commands now need
matching installed SD resources. Bluetooth, crypto, device_info, storage and
memory/recovery servicing remain resident; do not copy the upstream bt stack
reduction or make Bluetooth initialization depend on SD availability.

### Static FAAC TM, external Core module

Adapt [Unleashed24f539c3](https://github.com/DarkFlippers/unleashed-firmware/commit/24f539c3821c6a25b5348dc96afba4fcc5ef7dea)
as protocol_faac_tm.fal, not another resident decoder. It supports12-DIP static
FAAC TM receive/save/load/explicit send at433/868MHz; it is not FAAC SLH or a new
key-search scenario. Enforce exact width/key bounds, bounded bit counting,
two matching frames, per-file TE/repeat defaults and rewind/error handling.
Keep the existing decoder/encoder ABI and public API unchanged.

CAME12 disambiguation uses the measured clock and inter-frame gap, preserving
the existing fast CAME path and18/24/25-bit formats. Synthetic FAAC35Te frames
must not be claimed as slower CAME47Te frames. Add868.000MHz as an explicit
frequency choice only; the default six hopping frequencies are unchanged.

No Add Manually entry is advertised in this batch. Its lazy Core-host routing
and TE generation need a separate checked implementation; simply copying the
upstream generator does not satisfy our host/plugin contract. Physical FAAC/CAME
captures and receiver behavior still need owner testing, not an assumed pass.

### Selective RAW Edit1.8

Compare author main `593991914861e7ffc31f6c3b78a31332ab5c057a` and the exact
Community source. Open an input key file read-only, copy at most16KiB to RAM
with total/contiguous heap headroom, and invoke its encoder on that copy. Some
encoders update Key/Counter through FlipperFormat; those writes must never
reach the imported file. Short copies, failed rewinds, oversized inputs and
insufficient memory fail closed. A successful merge retains synthesized-frame
metadata so the synchronization guard is not trimmed as noise.

An explicitly selected external Core protocol can temporarily load its registry
for synthesis; built-in formats do not load it. Release transmitter/environment
before unloading the registry. Do not change active pack settings or transmit.
Zero-gap merge and bounded NumberInput controls were already present. The new
upstream custom-button picker is not included without separate UI/lifecycle
review. Version1.8 identifies this documented fork, not full source parity.
This fixes an input-mutation risk; it does not establish what caused any earlier
missing user recordings.

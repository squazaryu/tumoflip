## Selected upstream change

[Official firmware #4515](https://github.com/flipperdevices/flipperzero-firmware/pull/4515)
(Zu, `0c87c9e2df068848dff786f2851dd360e24a75f9`) fixes the lifetime of the
Bluetooth key-storage listener. Keep the listener and its context in the HAL
for the lifetime of the Bluetooth service, reinstall them after each new
BleGlue initialization, and register before key settings can restart the
radio. Preserve the existing peer-selection, pairing, and key-storage
policies. This does not change Companion's connection status logic.

## Original addition: Field Tools 1.1

Start or resume an object round, select an object, and open **Check linked
files**. Read the selected card, then query SD metadata for up to eight links:
`Present` (nonempty file), `Missing`, `Empty`, `Folder`, or `Not checked`.
If the card cannot be loaded, or the SD becomes unavailable during the check,
report no result instead of treating partial observations as success.
**Back** returns to the same object. No linked file is opened, sent, restored
or modified; no result or note is written. A present file says nothing about
its contents or any receiver.

The already-installed path remains `/ext/apps/Tools/field_tools.fap`.
No app migration, new exports or iOS change. The next coordinated FW Packages
update should carry the rebuilt FAP at that path.

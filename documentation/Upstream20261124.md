## Selected adaptation

[Unleashed 6f9d96f6](https://github.com/DarkFlippers/unleashed-firmware/commit/6f9d96f6ac035cdfb7c4b38b411c3e03693d974d)
adds a visible marker for the already supported KeeLoq timing of 200 us:
`KL HR <manufacturer>` in history and `KeeLoq 66b HR` in details.
Standard timing keeps its existing text.

Tumoflip preformats the name as `KL <manufacturer>` before the shared history
formatter. The local adaptation handles both that alias and the original
protocol name, so it also works in ARF's shared formatter. Missing, invalid or
unreadable TE/manufacturer metadata does not acquire an HR label.

No decoder timing, transmitter, button action, key calculation, stored Protocol,
saved Key, file layout, API export or package route changes. The public timing
constant moves to the existing source header; no API bump.

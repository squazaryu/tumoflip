## Adaptation

[Unleashed 26a9c8a6](https://github.com/DarkFlippers/unleashed-firmware/commit/26a9c8a62f00deb01d57345c5c36451d1dedac29)
imports Lechnio's RAW Edit v2.0. Tumoflip keeps its existing direct-open
contract and makes a smaller display-only change in RAW Edit 1.10:

- Fit the original filename to the screen in pixels. If it does not fit,
  show both its beginning and distinguishing suffix without a scroll timer.
  The renderer uses a fixed stack buffer and never cuts through a UTF-8
  continuation sequence.
- Keep the loading state until the first view and markers are ready.
- Keep the app ID, author, license, category and storage behaviour. The
  display path is not used to choose or overwrite a save target. The existing
  public canvas measurement function is available in API 88.23; no API bump.

The new tests use synthetic names and the source contract only. No RF capture,
transmission, hardware or full package build was run. A future FW Packages
release would require its normal artifact checks; no release was started here.
